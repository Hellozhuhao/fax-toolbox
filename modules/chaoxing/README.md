# 学习通模块（Windows 起步版）

工具箱左侧选择“学习通刷课”，右侧在独立 WebView2 会话中打开学习通。用户自行登录并进入具体课程的学习页；“开始自动完成”只在课程学习页可用。密码箱通过“系统选项”打开，保存账号需要用户主动在原生窗口输入，工具箱不会读取登录表单。

## 已实现

- Rust 会话状态：开始、暂停、停止、等待答案；每条页面观察按会话代数和序号校验。
- 视频发现、播放、中断后重试、播放结束后切下一节；学习目标页尝试切换“视频”页签。
- 文档页面识别、翻页和最后一页后切下一节；同源或不同子域名 iframe 由 WebView2 frame 消息承载。
- 章节答案库按课程 URL 的 `chapterId` 匹配。按题号录入单选/多选字母、判断题“对/错”或填空/简答文本；多空用 `|` 分隔。识别原生 radio/checkbox、文本框与部分学习通自定义选项。题目数量或结构不匹配时暂停，避免猜测提交。
- 只处理没有表单控件的普通“继续播放/继续学习/我知道了”提示。
- 密码箱使用 Windows DPAPI 当前用户范围加密账号和密码；Rust 后端只接收密文并持久化。

## 尚需真实账号验证

本地夹具覆盖了视频、测验和嵌套文档，但未使用真实学习通账号验证登录跳转、课程结构、任务点完成判定与学校单点登录。当前没有迁入旧脚本的 AI 答题、字体混淆识别、所有弹窗策略及全部站点布局候选。对这些页面会停下或保持当前页，用户可暂停并人工处理。不能据夹具通过推断真实课程已完成。

页面适配器只处理 DOM；课程决策和答案匹配在 Rust 中。无需管理员权限或 root。定时检查间隔为 2.5 秒，DOM 变化合并到约 150 毫秒后处理；待真实场景数据到手后再分析瓶颈与兼容性。
