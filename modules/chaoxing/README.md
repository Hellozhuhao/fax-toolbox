# 学习通模块（Windows 起步版）

从“模块”打开“学习通刷课”后，右侧在独立 WebView2 会话中打开学习通。用户自行登录并进入具体课程的学习页；“开始自动完成”只在课程学习页可用。密码箱通过“系统选项”打开，保存账号需要用户主动在原生窗口输入，工具箱不会读取登录表单。

## 已实现

- Rust 会话状态：开始、暂停、停止、等待答案；每条页面观察按会话代数和序号校验。
- 视频发现、播放、中断后重试、播放结束后切下一节；学习目标页尝试切换“视频”页签。
- 文档页面识别、翻页和最后一页后切下一节；同源或不同子域名 iframe 由 WebView2 frame 消息承载。
- 章节答案库按课程 URL 的 `chapterId` 匹配。按题号录入单选/多选字母、判断题“对/错”或填空/简答文本；多空用 `|` 分隔。识别原生 radio/checkbox、文本框与部分学习通自定义选项。题目数量或结构不匹配时暂停，避免猜测提交。
- AI 答题可接入兼容 Chat Completions 的 HTTPS 服务，包括提供免费额度的服务。用户在工具箱原生窗口配置完整 `/chat/completions` 地址、模型名和 API Key。没有本章答案或答案与页面不匹配时，工具箱提取当前可见题目和选项，请求模型并校验完整题号、选项范围与填空数后自动填写。模型无法给出完整答案、页面变化或请求失败时保持人工处理状态。模型答案可能有误，提交结果需要留意。
- API Key 仅经过原生窗口输入，使用 Windows DPAPI 当前用户范围加密保存在本机 `ai-settings.json`；WebView 页面和 Rust 后端不接收密钥。AI 请求直接联网，不使用代理。仅发送当前题目文本和选项，不发送账号、Cookie 或课程 URL。请仅配置你信任的服务。
- 工作台从当前课程目录提取章节名称与标识，允许在目录中选择并跳转；Rust 将章节标识和名称保存到本机 `catalog.json`，不保存目录链接中的登录参数。网页没有暴露可识别目录时保留已保存的名称，并提示在右侧手动选择。
- 工作台和网页按窗口宽度分配空间，中间分隔线可拖动；工具栏可暂时收起左侧控制面板，让课程网页使用完整宽度。
- 只处理没有表单控件的普通“继续播放/继续学习/我知道了”提示。
- 暂停会同步暂停页面适配器与正在播放的视频，并取消已排队的文档翻页；继续时重新观察当前页。离开课程页或页面加载失败时自动暂停任务。
- 遇到可见验证码、安全验证或视频需要人工点击播放时进入“等待人工操作”；工具箱不会自动完成验证，也不会伪造浏览器状态或学习时长。
- 密码箱使用 Windows DPAPI 当前用户范围加密账号和密码；Rust 后端只接收密文并持久化。

## 尚需真实账号验证

本地夹具覆盖了视频、测验和嵌套文档。AI 答题的解析与校验由本地测试验证；需要用户配置真实服务后才能验证实际模型调用。尚未覆盖字体混淆识别、所有弹窗策略及全部站点布局候选。对这些页面会停下或保持当前页，用户可暂停并人工处理。不能据夹具通过推断真实课程已完成。

页面适配器只处理 DOM；课程决策和答案匹配在 Rust 中。无需管理员权限或 root。定时检查间隔为 2.5 秒，DOM 变化合并到约 150 毫秒后处理；待真实场景数据到手后再分析瓶颈与兼容性。
