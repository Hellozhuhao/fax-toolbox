# Rust 后端模块边界

## 当前实现

Windows 外壳与 Rust 进程使用版本化 NDJSON 协议。Rust 进程只处理本地状态与存储，不直接持有 WebView2、Windows 密钥或第三方网站的登录信息。

```text
C# 外壳（来源校验、WebView2、DPAPI）
  └─ 标准输入 / 标准输出：协议 v1，每行最多 32 KiB
      ├─ protocol.rs：读取上限、JSON 信封、版本与错误响应
      └─ registry.rs：命令命名空间 → 唯一模块
          ├─ modules/smoke.rs：演示会话状态机
          ├─ modules/chaoxing/：课程状态、答案库、章节目录
          └─ modules/vault.rs：仅存储已由宿主加密的账号密文
```

`registry.rs` 只根据明确列出的命名空间分派请求。模块实现 `ModuleHandler`，拥有自己的内存状态和持久化文件；模块不能通过协议调用其他模块的内部方法。`system.ping` 属于宿主协议。新增内置模块时，在 `modules/` 增加实现，再在注册表中声明命名空间。未知命名空间返回 `UNKNOWN_METHOD`，不会回退到某个默认模块。

### 接口与数据所有权

| 边界 | 拥有者 | 当前接口 / 数据 |
| --- | --- | --- |
| 消息解析 | `protocol.rs` | 版本、请求 ID、大小上限、JSON 解析、统一响应 |
| 命令分派 | `registry.rs` | `session.*`、`course.*`、`answers.*`、`catalog.*`、`vault.*` |
| 演示模块 | `smoke.rs` | `toolbox.smoke` 会话、代数、事件序号、状态迁移 |
| 学习通模块 | `chaoxing/` | 课程会话、`answers.json`、`catalog.json` |
| 密码箱服务 | `vault.rs` | `vault.json` 中的密文；明文只在 C# 原生窗口出现 |

现有文件名和位置保持不变，以便当前用户数据无需迁移。代码所有权已经收回各模块：其他模块不直接读写答案库、目录或密码箱文件。若未来改为按模块分目录，必须提供有回滚能力的显式迁移；不能简单移动文件后让旧用户数据消失。

## 为什么采用静态注册

目前模块都随 EXE 一起发布。静态注册让可调用命令和存储所有者一目了然，也避免把下载的任意原生代码装入高权限进程。`ModuleHandler` 让新增内置模块保持一致的接口。若将来需要第三方插件，应先设计签名、版本、能力清单、独立进程和资源限制；当前的 trait 不是插件安全沙箱。

Rust 后端目前是单进程串行请求处理。小 JSON 请求和状态机操作很快，也保持了响应顺序。耗时模型调用和 WebView2 交互仍由 C# 管理，不应放进这个同步循环。计算任务只有经过性能测量后才加入专用工作线程或 C/C++ 库，并通过有超时、有大小上限的结果消息回到主循环。

## 安全与稳定性约束

1. 输入由有界读取器处理。超过 32 KiB 的行会被丢弃直到换行，下一条请求仍可正确解析；不会先将整行装入内存。
2. 每个方法在所属模块再次验证参数、会话代数、序号与允许状态。网页不能通过构造 Rust 方法名获得密码箱或文件系统能力。
3. 演示模块最多保留 256 个会话；达到上限时清除已结束会话，活动会话仍超过上限则拒绝创建。
4. 密码箱由 Windows DPAPI 在 C# 端加密。Rust 只校验并持久化密文，不持有加密密钥。
5. 当前隔离是命令与状态边界。所有 Rust 模块仍共享一个进程；未来若需要运行不受信任的插件或抵御模块级 panic，应采用独立子进程，而不是仅依赖 trait。
6. C# 对课程网页的异步导航处理现在捕获错误并报告到 UI，避免单次后端请求失败直接终止桌面进程。

## 新模块开发步骤

1. 在 `src/modules/<id>/` 实现 `ModuleHandler`，仅导出请求入口和必要的构造函数。
2. 在 `registry.rs` 为新命名空间添加显式路由；检查与已有命名空间无重叠。
3. 让模块构造函数获得自己的数据位置，不把其他模块的存储结构传进去。
4. 在 `packages/protocol/WINDOWS_PROTOCOL.md` 增加方法、参数、错误和生命周期说明。
5. 写模块状态与越界输入的测试，再用发布版 EXE 跑 C# → Rust 端到端夹具。

## 验证

`cargo test --locked --manifest-path apps/rust-backend/Cargo.toml` 覆盖状态迁移、目录与答案数据、密码箱文件保护、命名空间隔离及超长输入恢复。`scripts/build-windows.ps1 -Test` 运行桌面与后端的隐藏窗口回归，包括模块切换。外部真实网站和第三方 AI 服务仍需要用户在其账号环境中进行交互验证。
