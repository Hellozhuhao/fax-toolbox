# 前瞻版 · v0.1.0-preview.1

这是 Fax Toolbox 的第一个 Windows x64 预发布版本。

## 下载与安装

- **推荐：**下载 `FaxToolbox-Setup-v0.1.0-preview.1-win-x64.exe`，双击安装。安装在当前用户目录下，无需管理员权限；可选桌面快捷方式，支持从 Windows 设置卸载。
- **免安装：**下载 `FaxToolbox-Windows-win-x64.zip`，完整解压后运行 `FaxToolbox.Windows.exe`。不要只提取 EXE。
- 安装器内含微软签名的 WebView2 引导程序；机器缺少 WebView2 Runtime 时会联网安装。便携版需要先安装 WebView2 Runtime。
- 两种版本均包含 Windows 前端、Rust 后端和页面资源，无需另装 .NET 运行时。账号、密码、浏览器缓存和 API Key 未打入安装包。

## 当前功能

- Fax Toolbox 主界面、独立任务标签、工具与状态页面。
- 学习通课程页面、视频与测验状态检测、自动答题和章节推进辅助。
- 作业校对、答案与详解画板；学习与作业共用配置入口，但各自任务隔离。
- 状态页提供运行日志和在线调试入口，方便定位网页适配问题。

## 预览版提示

- 学习通网页会调整结构，自动识别和答题可能需要人工检查。提交测验前请核对答案。
- 已收到学习通消息内容在内嵌网页中空白的反馈，仍需根据状态日志定位；本版不能保证该页面正常显示。
- 安装包尚未使用 Fax Toolbox 代码签名证书签名。可用同页 `SHA256SUMS.txt` 校验下载文件。

## 从源码构建

需要 Windows x64、.NET 10 SDK、Rust 工具链、Visual Studio Build Tools 和 Inno Setup 7。运行 `powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1 -Test`。便携版运行 `powershell -ExecutionPolicy Bypass -File scripts/package-windows.ps1 -SkipPublish -Test`。详细说明见仓库 README。
