# 前瞻版 · v0.1.0-preview.2

这一版修复学习通章节识别和视频内弹题的状态处理，并加入可在软件运行时读取的诊断信息。

## 下载与安装

- 推荐下载 `FaxToolbox-Setup-v0.1.0-preview.2-win-x64.exe`，双击安装。现有用户可直接安装升级。
- 免安装版本为 `FaxToolbox-Windows-win-x64.zip`；请完整解压后运行 `FaxToolbox.Windows.exe`。
- 安装包自带 WebView2 引导程序，缺少运行环境时会联网安装；应用本身无需另装 .NET 运行时。

## 本版变化

- 稳定当前章节显示，不再因网页短暂重绘或旧 URL 将章节反复清空。
- 识别与视频处于同一章节的测验，以及视频画面上的无题号选择题；页面明确判错后，AI 会排除已判错的组合并有限次重试。
- 对模型回复、页面提交和结果确认分别更新状态；提交未确认时会停止并提示检查。
- 状态页可导出诊断日志。设置中的开发者模式默认关闭；开启后可分析页面并复制结构、可见内容和状态，也可通过同用户本机管道读取运行中快照。安装目录包含 `scripts/read-live-diagnostics.ps1`。
- 工具子菜单在悬停片刻后出现，保留键盘焦点操作；减少页面与窗口切换中的重复 WebView2 重排。
- 学习通可加密保存当前登录状态，下次启动自动恢复，无需再次手工录入账号密码到密码箱。

## 预览版提示

- 学习通网页结构可能变化，无法可靠识别或连续五次答错时会等待人工检查。
- 内嵌学习通消息页内容空白的问题仍在排查，可在开发者模式下导出页面分析协助定位。
- 安装包尚未使用 Fax Toolbox 代码签名证书签名；请用同页校验文件核对下载内容。
