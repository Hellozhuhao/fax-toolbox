# Fax Toolbox · Beta 版

Windows 64 位版本，版本号 **0.2.0-beta.1**。

## 下载与安装

- **推荐：FaxToolbox-Setup-v0.2.0-beta.1-win-x64.exe**。原生动画安装器，支持安装路径选择、桌面快捷方式和安装后启动。默认安装到当前用户账户，不需要预先安装 .NET。
- **FaxToolbox-Windows-v0.2.0-beta.1-win-x64.zip**：便携版，解压后运行 `FaxToolbox.Windows.exe`；需要已安装 WebView2 Runtime。
- **SHA256SUMS.txt**：发布文件的 SHA-256 校验值。

安装器先检测 WebView2，仅在缺少时从微软官方下载、验证微软数字签名并安装。网络下载或安装失败会显示原因并允许重试。已有 WebView2 时无需联网下载运行环境。.NET 与后端 C/C++ 运行库均随程序提供，无需额外安装 VC++ 运行库。

安装版可在 Windows 设置中卸载；升级和卸载保留本机用户数据、模型密钥和会话记录。安装前请关闭目标安装目录中的工具箱窗口。不要从开始菜单的旧快捷方式启动便携版。

## 本次更新

- 网络管家：Mihomo 官方内核、Xray 节点导入和配置回退、自动检测连接与应用、简化配置流程。
- 工具箱视觉：星轨、书页、校对笔、指南针等模块插画，修复图标错位及模块标签混入首页。
- Agent：Chat / Code 模式、工具调用与权限确认、会话、记忆池、流式输出、Markdown 表格与超链接、文档附件和消耗保护。
- 模型连接：国内云端、本地模型、自定义接口及 NoTrack 配置。
- Beta 安装器：统一视觉风格、星轨与页面过渡动画、自动依赖安装、路径选择和卸载支持。

## 验证与使用边界

已验证独立中文空格路径的安装、安装后的 Agent 界面回归及卸载；覆盖运行环境已存在、缺失、下载失败、验签失败和安装后复检失败的测试。缺少 WebView2 的流程通过模拟测试验证，未卸载测试电脑已有的系统运行环境。

网络管家依据应用状态切换系统代理，不提供 TUN 强制按进程分流。Mihomo 安装与节点导入不会自动切换当前网络，需在模块中点击启用代理。

这是 Beta 版本。安装包尚未使用发布者代码签名证书签名，Windows 可能显示未知发布者提示。随包分发的 Mihomo 许可证见 `modules/proxy-autoswitch/MIHOMO_LICENSE.txt`。
