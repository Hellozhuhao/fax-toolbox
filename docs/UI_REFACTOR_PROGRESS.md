- 保留全部模块、操作入口、字段 ID、宿主命令与参数。外观变化不启动、停止、提交或批准任务。

## 已确认的后续问题

1. 已修复：Agent 运行选项浮层缺少 Escape / 焦点返回和低高度定位，切换视图可能保留打开状态。
2. 已修复：窄窗口学习分类的图标点击与关闭逻辑不一致；Agent 侧栏缺少清楚的关闭入口与键盘退出。
3. 已修复：网络表单中的必填输入位于折叠的高级设置中，浏览器原生校验可能无法聚焦隐藏字段；错误只有全局反馈，用户难以定位并修正。
4. 已修复：长模型名在窄窗口挤压发送入口；创建分区、会话重命名及快速搜索中的中文候选确认可能被误当成提交。
5. 已修复：网络保存期间收到较早的状态回复会覆盖草稿并显示假成功；目前仅接受与本次提交一致的配置回显作为成功确认，错误回复仍保留输入供重试。放弃修改后，连接卡片的选择标记也跟随已保存配置恢复。
