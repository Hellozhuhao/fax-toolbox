# 生成检测调整

- 移除 DeepSeek/NoTrack 的本地 `max_tokens` 参数，不再按思考档位限制正文长度。
- 移除正文字符数、生成字节数、思考字节数及整轮累计 12,000 token 的硬熔断。
- 保留生成速度和实际用量显示；快速完成的流式回复也能报告估算 token。
- 文本重复检测要求至少四个相邻相同块、合计至少 768 个字母或数字。散落于不同段落的共同引用不会被视为循环。
- 工具重复检测同时比较操作、参数及结果，结果发生变化时允许继续；连续相同结果或重复循环才视为没有新进展。原有工具调用次数边界、参数验证及用户权限确认保留。
- 活跃的流式响应不受总时长超时限制。连接建立超时及连续 90 秒没有任何数据的空闲超时保留。
- 服务商返回 `finish_reason=length` 时，正文和用量正常保存，显示“继续生成”按钮。按钮必须由用户点击，不会自动追加付费请求，也不影响未发送的草稿。
- 旧会话以“模型达到本次输出上限”错误结尾时，也能显示继续入口。长正文及思考记录不再被会话事件的 12,000 字符截断。
- 学习通/作业校对仍验证完整 JSON；不完整的工具参数、异常协议响应和断开的流不会执行操作。

自动审批审核拒绝了取消全部调用边界并无限自动续写的方案，理由是循环请求、资源耗尽和不可控费用。最终采用一次点击发起一次续写请求的实现。

离线验证覆盖 120,000 字符正文、16,000 字符思考、45,000 token 用量、服务商截断标记、非相邻重复引用、真正重复段落、变化中的工具结果、稳定工具循环以及手动续写界面和完整消息保存。没有为这些测试请求云端模型。
