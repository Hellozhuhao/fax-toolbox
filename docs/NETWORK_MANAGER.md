# 网络管家

根据运行中的应用，在系统代理和直连之间自动切换。首次使用沿用桌面 `VPNsetting/auto-switch.json` 的连接与规则，原 VBS 和脚本保留。

## 快速设置

1. 打开 **网络管家**，自动检测当前代理内核、同目录配置与运行中的应用。
2. 在 **选择连接** 中点击一张连接卡片，自动填入内核、配置和本机端口。需要添加应用时，先运行它再点击 **重新检测**，也可以选择应用 EXE。
3. 在 **选择应用** 中设置代理或直连；原有应用规则会显示并保留。选择双方同时运行时的优先规则，点击 **保存配置**。
4. 点击 **检查连接**，然后选择 **启用代理** 或 **启动自动切换**。检测与选择不会自行启动任务，开机启动需单独启用。
5. **停止并还原** 恢复模块启用前的系统代理和用户代理环境变量。修改连接前应停止本模块的监控和内核。

路径、进程名、游戏安装路径识别、空闲策略和检查间隔放在默认收起的 **高级设置**。检测只检查已配置位置、常见内核位置、运行中的进程和它们的配置目录，不扫描整个磁盘。已保存但未运行的应用仍可选择；无法识别的连接可以在高级设置中手动填写。

默认每 3 秒检查一次，状态稳定 6 秒后切换。后台监控独立于工具箱窗口，关闭窗口不会终止监控。

## Mihomo 内核

内置安装入口采用 [Mihomo 官方稳定版 v1.19.32](https://github.com/MetaCubeX/mihomo/releases/tag/v1.19.32) Windows amd64 v1，安装前校验 SHA256：

```
00549b347d8e124600e46cac67d59293358454f465e9d86d2511567da56b7029
```

**安装并导入现有节点** 将当前 Xray 的 Shadowsocks / SOCKS5 节点转换为独立的 Mihomo 配置，保留支持的域名、IP 和网络分流规则。leastPing 自动选择组转换为定时测速组。原内核与原配置保留，可通过 **恢复 Xray 配置** 切回。

安装使用独立端口 `127.0.0.1:10819`，只准备文件并校验配置；启用代理后才生效。当前外部 Xray 进程不会被终止。安装不修改系统代理，不开启 TUN。

导入会在本机复制节点凭据和现有 GeoIP / GeoSite 数据；不会上传或在界面展示凭据。绑定网卡的节点保持原网卡绑定。无法转换的协议、组合路由和特殊传输会明确拒绝导入，应使用原生 Mihomo YAML / JSON 配置。Xray 的自定义 DNS 设置不迁移，导入后使用系统域名解析；复杂 DNS 配置需在原生 Mihomo 配置中设置。

## 运行与恢复

- 本机代理端口就绪后才更改系统代理。启动前由实际内核检查配置。
- 应用规则控制整台电脑的系统代理开关；同时运行的应用按优先规则处理。游戏安装路径自动识别可在高级设置调整。
- 系统代理只影响遵循 Windows 代理设置的应用。此模块不实现 TUN 或同时按不同进程强制分流。
- 更改后通知 WinINet；用户环境变量只影响新启动的应用，现有程序可能需要重启。
- PID、路径与启动时间共同验证进程归属。只停止本模块启动的内核，保留外部内核。
- 旧监控接管需确认；匹配原脚本路径，备份并撤下旧启动项。专用启动项为 `FaxToolbox-ProxyAutoSwitch.vbs`。
- 恢复前检查当前设置是否仍属于本模块；保留其他程序随后作出的代理更改。
- 错误退避最多每 60 秒重试一次；日志自动轮转，界面显示最近 30 条。
- 数据位于 `%LOCALAPPDATA%/FaxToolbox/proxy-autoswitch`。Agent 的任务控制仍需显示具体操作并确认执行。
