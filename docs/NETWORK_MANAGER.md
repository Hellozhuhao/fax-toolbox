# 网络管家

工具箱中的独立网络模块，用于根据当前应用在本机代理和直连之间切换。首次打开会读取桌面 `VPNsetting/auto-switch.json` 的路径与应用规则。原 VBS 和脚本不修改。

## 使用

1. 在首页、工具目录或网络工具分类打开 **网络管家**。
2. 核对 HTTP 代理地址、内核 EXE 和现有 JSON 配置。默认识别用户目录下的 Xray。
3. 保存配置，检查连接，再启动自动切换。启动不隐式启用开机启动。
4. 工作与游戏同时运行时，选择游戏优先或工作优先。默认沿用游戏优先；使用 AI 时可选择工作优先，避免代理连接被游戏规则中断。
5. **停止并还原** 恢复模块首次修改前的系统代理、用户代理环境变量。开机启动可单独关闭。

默认每 3 秒检查一次，应用状态稳定 6 秒后切换。后台监控独立于工具箱窗口，关闭窗口不会终止监控。保存配置需要先停止自动切换。

## 实现与保护

- 代理端口就绪后才更改系统代理。已有内核但端口错误会明确报错，避免重复启动。
- 启用时通知 WinINet 更新代理；用户环境变量仅影响新启动的应用。
- 使用每用户命名互斥锁防止多实例。PID、可执行文件路径和启动时间共同验证进程归属。
- 只停止由本模块启动的内核，保留外部内核；停止监控先请求正常退出，再在超时后处理自身进程。
- 旧监控接管需用户确认；准确匹配原脚本路径，备份并撤下其自动切换启动项，避免互相覆盖。原启动项备份保存在模块数据目录。专用启动项为 `FaxToolbox-ProxyAutoSwitch.vbs`。
- 还原时检查当前设置是否仍属于本模块。其他程序随后更改的代理设置会保留并写入日志。
- 错误退避重试最多每 60 秒一次；日志自动轮转，界面显示最近 30 条。
- 模块数据保存在 `%LOCALAPPDATA%/FaxToolbox/proxy-autoswitch`。只引用所选代理配置路径，不复制或展示节点凭据。
- Agent 可通过 `open_module(proxy)` 打开模块，通过 `module_action(proxy, start/stop/on/off)` 控制；执行前仍显示具体操作并请求确认。旧脚本接管和开机启动由模块界面处理。

系统代理只影响遵循 Windows 代理设置的应用，不能替代 VPN 隧道或对所有游戏强制路由。配置错误、代理节点故障和站点拒绝仍需对应处理。
