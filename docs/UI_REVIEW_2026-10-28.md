# 工具箱界面与交互复核 · 2026-10-28

本轮范围为整个工具箱，包括原生外壳、首页、工具目录、Agent、学习通、作业校对、网络管家、设置、状态、皮肤、密码箱、投屏和安装器。

## 已修复

- Windows Agent 回归使用了旧版运行概览容器和已移除的悬停导航逻辑。改为检验实际状态 tabpanel、工具目录入口、右键菜单及 Escape 关闭，并输出具体失败阶段。浏览器回归直接执行 C# 中同一段检查，避免两套选择器继续漂移。
- 顶部返回在模块网页没有历史时，回退到工具箱上一页。长标签列表限制在可滚动区域中，当前标签自动进入可视范围；操作按钮和关闭目标增大。
- 同一页面重复导航不再重复请求宿主布局、激活模块与读取配置。原生皮肤未变时保留标签更新并跳过重复配色和脚本注入。
- 流式回复不再触发全页面下拉控件扫描；累积文字保留文本节点，隐藏页面和快照恢复减少滚动布局读取。下拉鼠标高亮只更新受影响项目。
- 思考深度滑杆只更新当前数值和填充，松手后提交一次；模型未变化时保留列表和焦点。忙碌时禁用相关配置。
- 工具使用紫、青绿、琥珀、玫瑰等语义色，沿用全局皮肤变量；按钮、图标操作、开关、滚动条和滑杆采用清晰且可操作的尺寸，兼容高对比度与减少动画。
- 绘图加入对话后，附件曾按原图尺寸撑大输入区。改为有高度上限、可滚动的缩略图托盘；检查窄窗口多附件和审批区共存，发送按钮保持可见。绘图清空/取消与主要操作区分，附件移除操作增加明确名称。
